**Question for this chapter:** how do we turn the fixed-point results into an algorithm? [Chapter 3](/en/note/强化学习的数学原理-3-贝尔曼最优化公式) established that $T_*$ has the unique fixed point $v^*$. Here we compare three ways of reaching it when the environment model is known.

[Series guide](/en/note/强化学习的数学原理-0-阅读指南) · [中文摘要](/note/强化学习的数学原理-4-价值迭代与策略迭代)

## Value iteration

Start with any finite vector $v_0$ and repeatedly apply

$$
v_{k+1}(s)=\max_a\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_k(s')\right].
$$

Each update asks: if $v_k$ were the future-value estimate, which action would give the best immediate reward plus continuation? All states read the old vector in a **synchronous sweep**. Updating entries in place is a different scheduling choice; the proof we use here is for synchronous updates.

```text
v ← initial vector
repeat:
    v ← T_* v                 # evaluate all RHS entries using the old vector
    rho ← ||T_* v - v||_infinity
until rho ≤ tolerance
pi ← a policy greedy with respect to the returned v
```

The contraction proof immediately gives $\|v_k-v^*\|_\infty\le\gamma^k\|v_0-v^*\|_\infty$. It also gives the residual bound

$$
\|v-v^*\|_\infty\le\frac{\|T_*v-v\|_\infty}{1-\gamma}.
$$

Be careful about the returned policy: recompute the greedy actions from the returned vector rather than accidentally retaining actions chosen from the previous vector.

### Following the first two sweeps

For the Gridworld from Chapter 1 and $v_0=(0,0,0,0)^T$,

$$
v_1=(0,1,1,0)^T,\qquad v_2=(0.9,1,1,0)^T=v^*.
$$

The reward first reaches $B$ and $C$, then propagates one step back to $A$. This is a special short-path example; general discounted MDPs do not necessarily reach the exact answer in finitely many sweeps.

A greedy policy chooses $D$ at $B$, $R$ at $C$, and either action at $A$. Our code resolves exact ties by choosing $R$.

### A value tolerance is not a policy-loss tolerance

If $\pi$ is greedy with respect to $v$ and $\delta=\|v-v^*\|_\infty$, then

$$
\|v^*-v_\pi\|_\infty\le\frac{2\gamma\delta}{1-\gamma}.
$$

To derive it, insert $T_*v=T_\pi v$ between $T_*v^*=v^*$ and $T_\pi v_\pi=v_\pi$, and apply contraction to each difference. The result is at most $2\gamma\delta+\gamma\|v^*-v_\pi\|_\infty$, which rearranges to the bound above.

Combining it with the residual bound gives $2\gamma\rho(v)/(1-\gamma)^2$ as a sufficient policy-loss bound. It can be conservative, but it explains why the meaning of “tolerance” should be stated explicitly.

## Policy iteration

Instead of updating an approximate value vector directly, alternate two operations:

1. **Evaluate:** solve $v_{\pi_k}=T_{\pi_k}v_{\pi_k}$ for the current policy.
2. **Improve:** choose $\pi_{k+1}$ greedy with respect to $q_{\pi_k}$.

```text
pi ← initial deterministic policy
repeat:
    v ← solve (I - gamma P_pi) v = r_pi
    pi_new ← greedy(r + gamma P v)
    if pi_new = pi: return v, pi
    pi ← pi_new
```

The expression in the greedy step is computed separately for each state and action. It is not the policy-averaged $P_\pi$ used during evaluation.

### Why policy improvement works

Greediness ensures

$$
T_{\pi_{k+1}}v_{\pi_k}\ge T_{\pi_k}v_{\pi_k}=v_{\pi_k}.
$$

Let $d=T_{\pi_{k+1}}v_{\pi_k}-v_{\pi_k}\ge0$. Subtracting the evaluation equations gives

$$
v_{\pi_{k+1}}-v_{\pi_k}
=(I-\gamma P_{\pi_{k+1}})^{-1}d\ge0.
$$

Thus no state's true value gets worse under exact evaluation and exact greedy improvement. If there is no improvement left, $v_\pi=T_*v_\pi$, so uniqueness of the optimality fixed point implies $v_\pi=v^*$.

There are finitely many deterministic policies. With a consistent tie rule, policy iteration terminates: unless the current value is already optimal, the improvement vector is nonzero and some state's value increases strictly. If the value is already optimal, a fixed tie rule selects the same canonical greedy policy on the next evaluation. Repeated arbitrary switching between tied actions would obscure this stopping argument.

### Policy iteration by hand

Initialize the policy to choose $R$ everywhere. At $B$ it then loops forever with zero reward. The evaluations and improvements are

| Round | Actions at $(A,B,C)$ | Evaluated values at $(A,B,C)$ | Next greedy actions |
| --- | --- | --- | --- |
| 1 | $(R,R,R)$ | $(0,0,1)$ | $(D,D,R)$ |
| 2 | $(D,D,R)$ | $(0.9,1,1)$ | $(R,D,R)$ |
| 3 | $(R,D,R)$ | $(0.9,1,1)$ | Unchanged; stop |

Round 2 is already optimal. Round 3 occurs because the fixed tie rule changes the action at $A$. Counting this extra round as a failure to improve would confuse policy identity with policy value.

## Truncated policy iteration

Exact evaluation can be expensive. A compromise is to take only $m\ge1$ Bellman evaluation sweeps between greedy improvements:

$$
\begin{aligned}
\pi_{k+1}&\in\operatorname{Greedy}(v_k),\\
w_0&=v_k,\\
w_{j+1}&=T_{\pi_{k+1}}w_j,\qquad j=0,\ldots,m-1,\\
v_{k+1}&=w_m.
\end{aligned}
$$

The policy stays fixed during the inner sweeps. The warm start is the previous value estimate, not a fresh zero vector each time.

- With $m=1$, $v_{k+1}=T_{\pi_{k+1}}v_k=T_*v_k$, exactly value iteration.
- With increasingly accurate evaluation, the inner solve approaches the policy-evaluation step of policy iteration.
- For finite $m$, $v_k$ is generally an estimate, not the exact value of the accompanying policy.

### A sufficient convergence argument for our initialization

Our rewards are nonnegative, so $v_0=0$ satisfies $v_0\le T_*v_0$. More generally, suppose $v_0\le T_*v_0$ and $v_0\le v^*$. Given this property at step $k$, greediness and monotonicity give

$$
v_k\le T_*v_k=T_{\pi_{k+1}}v_k
\le(T_{\pi_{k+1}})^m v_k=v_{k+1}\le v^*.
$$

The inner sequence is increasing, so $T_{\pi_{k+1}}v_{k+1}\ge v_{k+1}$, and therefore $T_*v_{k+1}\ge v_{k+1}$. This maintains the induction hypothesis. The bounded increasing sequence has a limit $\bar v$. Taking limits in $v_k\le T_*v_k\le v_{k+1}$ and using continuity gives $\bar v=T_*\bar v$, hence $\bar v=v^*$.

This proves the case used by our implementation without claiming that an informal “between VI and PI” analogy is a proof. If rewards can be negative, a constant lower bound $v_0=R_{\min}\mathbf1/(1-\gamma)$ supplies the same initialization property.

## Reproducible comparison

Run the [shared script](/rl/ch1-6.py):

```bash
python ch1-6.py --output results.json
```

All three implementations use $\gamma=0.9$, the same transition table, and deterministic tie-breaking. VI and truncated PI stop at an optimality residual of at most $10^{-12}$. PI uses a linear solve and policy stability.

| Algorithm | Observed outer iterations | Work inside an iteration | Returned value |
| --- | --- | --- | --- |
| VI | 2 | One optimality sweep, plus residual check | $(0.9,1,1,0)$ |
| PI | 3 | Exact policy evaluation and greedy improvement | $(0.9,1,1,0)$ |
| Truncated PI, $m=2$ | 1 | Greedy choice, two fixed-policy sweeps, residual check | $(0.9,1,1,0)$ |

These are iteration counts, not a runtime ranking. An exact linear solve and a Bellman sweep have different costs; the unusually small grid also makes this example easy. The script checks values against both the analytic answer and enumeration of all eight deterministic policies on nonterminal states.

For a dense model with $n$ states and $m$ actions, a direct optimality sweep costs roughly $O(mn^2)$, while a generic dense policy-evaluation solve costs $O(n^3)$. Sparse or deterministic transitions change these costs substantially.

## Check your understanding

1. Can exact policy iteration reduce one state's value to improve another? **No:** its improvement theorem is componentwise.
2. Why may two correct implementations return different policies? **Tied actions** can produce identical optimal values.
3. Does a stable policy after a few approximate evaluation sweeps prove optimality? **No:** the value estimate may still be inaccurate; use the optimality residual or a suitable convergence argument.
4. What is still missing for learning from experience? **The model:** every update above needs transition probabilities and expected rewards. Monte Carlo replaces these expectations with sampled returns.
