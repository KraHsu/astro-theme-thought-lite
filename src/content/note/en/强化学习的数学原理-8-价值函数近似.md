**Question for this chapter:** how can a compact parameter vector represent values for many states, and what changes when one update affects several states? [Chapter 7](/en/note/强化学习的数学原理-7-时序差分方法) learned independent table entries. Here the entries share parameters.

[Series guide](/en/note/强化学习的数学原理-0-阅读指南) · [中文摘要](/note/强化学习的数学原理-8-价值函数近似)

The prerequisites are TD targets, matrix least squares, and the chain rule. We will derive linear prediction updates and their fixed points, explain approximate action-value learning and DQN, and exhibit a small instability that tabular intuition misses.

## Tables are a special feature map

Let $\phi(s)\in\mathbb R^k$ be a fixed feature vector and $w\in\mathbb R^k$ the parameters. A linear approximator is

$$
\widehat v(s;w)=\phi(s)^Tw.
$$

“Linear” means linear in $w$; features can contain nonlinear functions of the state. Stacking feature rows gives $\widehat v=\Phi w$. A tabular representation uses one-hot features: $\phi(s)=e_s$, so each weight is one state's value. Compact features trade exact representation for parameter sharing and generalization.

In our grid, fix the terminal value to zero by using $\phi(T)=0$. For the other states choose

$$
\phi(A)=(1,0)^T,\qquad
\phi(B)=\phi(C)=(1,1)^T.
$$

Then $\widehat v(A)=w_1$ and $\widehat v(B)=\widehat v(C)=w_1+w_2$. The uniform-policy truth is representable exactly by $w=(9/11,1/11)^T$. If we used only the constant feature 1 on all three nonterminal states, no single weight could represent both $9/11$ and $10/11$.

For a neural network $\widehat v(s;w)$, the feature transformation itself changes with $w$. The linear theory below therefore needs separate justification before applying it to a neural network.

## Define the fitting objective and its distribution

For a fixed policy and a fixed state weighting $d(s)$, define

$$
L(w)=\frac12\sum_s d(s)[\widehat v(s;w)-v_\pi(s)]^2.
$$

The weighting tells us where errors matter. A distribution concentrated on frequently visited states may fit those states well and neglect others. Let $D=\operatorname{diag}(d)$; then the linear objective is $\tfrac12\|\Phi w-v_\pi\|_D^2$, with $\|x\|_D^2=x^TDx$. If $\Phi$ has full column rank on positively weighted states, its minimizer satisfies

$$
\Phi^TD\Phi w_{\mathrm{LS}}=\Phi^TDv_\pi.
$$

For fixed-policy Monte Carlo samples with $S\sim d$ and $\mathbb E[G\mid S]=v_\pi(S)$, gradient descent can use

$$
w\leftarrow w+\alpha[G-\widehat v(S;w)]\nabla_w\widehat v(S;w).
$$

The return noise has zero conditional mean, so this is an unbiased stochastic gradient of the stated value-error objective when samples and parameters meet the usual conditional sampling assumptions.

### Stationary distributions require care in an episodic task

In a continuing finite ergodic chain, a stationary distribution obeys $d^TP_\pi=d^T$. It is useful in the source's linear-TD analysis. Under the uniform policy evaluated here, our absorbing grid has the unique stationary distribution concentrated on $T$, and its state distribution converges there from every starting state. That distribution would ignore every interesting state. This conclusion depends on the policy: always choosing right at $B$ creates another absorbing class, so the mere presence of a terminal state does not imply a unique stationary distribution.

Our approximation experiment instead samples $A,B,C$ independently with probability $1/3$, then takes one uniform-policy action. This is an explicitly chosen training distribution, not the stationary distribution of the absorbing chain. We check its small matrices directly. Resetting episodes also induces a useful sampling distribution, but reset transitions must not be mistaken for reward-bearing transitions in the original task.

## TD uses a semi-gradient

Replace the unknown value target with

$$
Y_t=R_{t+1}+\gamma\widehat v(S_{t+1};w_t).
$$

The usual TD update is

$$
w_{t+1}=w_t+\alpha_t
[Y_t-\widehat v(S_t;w_t)]\nabla_w\widehat v(S_t;w_t).
$$

It is a **semi-gradient** because it differentiates the current prediction while treating the target as fixed, even though that target contains $w_t$. For a linear approximator, the final factor is $\phi(S_t)$.

If we actually differentiated the sampled squared TD error $\tfrac12\delta_t(w)^2$, gradient descent would instead use

$$
w\leftarrow w+\alpha\delta_t(w)[\phi(S_t)-\gamma\phi(S_{t+1})].
$$

These are different update directions; the usual semi-gradient TD direction is not generally the gradient of a fixed scalar loss. Furthermore, the expected squared sampled residual is not the squared expected Bellman residual: it includes conditional target variance. Unbiased gradients of a squared expected Bellman residual generally require two conditionally independent next-state samples, the **double-sampling problem**. A “TD loss” in code does not by itself identify a population objective.

## The linear TD fixed point

For samples whose state distribution is $d$ and whose transitions follow the evaluated policy, expand the expected semi-gradient:

$$
\begin{aligned}
\mathbb E[\delta\phi(S)]
&=\Phi^TD[r_\pi+\gamma P_\pi\Phi w-\Phi w]\\
&=b-Aw,\\
A&=\Phi^TD(I-\gamma P_\pi)\Phi,\qquad b=\Phi^TDr_\pi.
\end{aligned}
$$

When $A$ is nonsingular, an equilibrium is $w_{\mathrm{TD}}=A^{-1}b$. This is a root of an expected update, not automatically the least-squares minimizer above. Define the weighted projection

$$
\Pi_D=\Phi(\Phi^TD\Phi)^{-1}\Phi^TD.
$$

Multiplying $Aw=b$ by $\Phi(\Phi^TD\Phi)^{-1}$ gives

$$
\Phi w=\Pi_D T_\pi(\Phi w).
$$

Thus TD seeks a **projected Bellman fixed point**: first apply the Bellman operator, then project the resulting vector into the representable feature space.

### Why on-policy stationary weighting helps

For a continuing chain with positive stationary weights, Jensen's inequality and stationarity imply

$$
\begin{aligned}
\|P_\pi x\|_D^2
&\le\sum_s d(s)\sum_{s'}P_\pi(s,s')x(s')^2\\
&=\sum_{s'}d(s')x(s')^2=\|x\|_D^2.
\end{aligned}
$$

Projection is nonexpansive in this norm, so $\Pi_DT_\pi$ is a $\gamma$-contraction on the feature space. For nonzero $z$ and full-rank $\Phi$, put $x=\Phi z$. Then

$$
z^TAz=x^TD(I-\gamma P_\pi)x
\ge(1-\gamma)\|x\|_D^2>0.
$$

This proves nonsingularity and stable mean drift, even though $A$ need not be symmetric. Standard linear stochastic-approximation results then give convergence under appropriate ergodicity, bounded-feature/reward, visitation, and decreasing-step conditions. Stability of the mean recursion alone is not a complete proof for arbitrary dependent noise.

A useful approximation bound follows by adding and subtracting $\Pi_Dv_\pi$:

$$
\|\Phi w_{\mathrm{TD}}-v_\pi\|_D
\le\gamma\|\Phi w_{\mathrm{TD}}-v_\pi\|_D
+\|\Pi_Dv_\pi-v_\pi\|_D.
$$

Hence the TD error is at most $1/(1-\gamma)$ times the best projection error in this setting. It need not achieve that best error. Arbitrary off-policy weights do not preserve the nonexpansiveness argument.

### A complete grid calculation

Omit the terminal coordinate, whose feature and value are zero. Under the uniform policy,

$$
P=\begin{bmatrix}0&1/2&1/2\\0&1/2&0\\0&0&1/2\end{bmatrix},
\qquad r=(0,1/2,1/2)^T,\qquad D=I/3.
$$

$P$ is substochastic because transitions into $T$ leave this three-state subsystem. For the single constant feature $\Phi=(1,1,1)^T$,

$$
A=1-0.9(2/3)=0.4,\quad b=1/3,\quad
w_{\mathrm{TD}}=5/6.
$$

The least-squares answer is the average true value,

$$
w_{\mathrm{LS}}=\frac{9/11+10/11+10/11}{3}=\frac{29}{33}.
$$

They are approximately $0.833333$ and $0.878788$: a concrete distinction between Bellman consistency after projection and the best fit to true values. With the two features introduced earlier, both methods recover the exact values because those values lie in the feature space and the corresponding systems are nonsingular.

## Approximate action values

For $\widehat q(s,a;w)$, Sarsa uses

$$
\delta_t=R_{t+1}+\gamma\widehat q(S_{t+1},A_{t+1};w_t)
-\widehat q(S_t,A_t;w_t),
$$

followed by $w\leftarrow w+\alpha\delta_t\nabla_w\widehat q(S_t,A_t;w)$. Approximate Q-learning replaces the next action with $\max_a\widehat q(S_{t+1},a;w_t)$. Both hold their targets fixed when computing this update. One-hot state-action features reproduce the tabular algorithms exactly; the script checks that identity.

Shared features can change unvisited pairs when one pair is updated. Changing the policy or taking a maximum also changes the target. The fixed-policy linear prediction theorem therefore does not establish convergence of approximate Sarsa control or approximate Q-learning.

### A minimal instability

Consider a separate two-state, zero-reward problem. The target transition sends both states to state 2. Use $\gamma=0.9$, scalar features $\phi(1)=1$, $\phi(2)=2$, and independent training-state probabilities $(0.99,0.01)$. Both states are covered, but these weights are not stationary for the target chain.

The expected update has

$$
A=0.99(1)(1-0.9\cdot2)+0.01(2)(2-0.9\cdot2)=-0.788,
\qquad b=0.
$$

Although the true value is exactly representable by $w=0$, a mean TD update with $\alpha=0.1$ gives $w_{k+1}=1.0788w_k$. Starting at 1, after 100 updates the weight is about 1968.31. The sign of the mean drift is wrong; reducing a fixed positive step only slows the divergence.

This illustrates the interaction often called the **deadly triad**: bootstrapping, function approximation, and off-policy or mismatched sampling. It is an independently specified counterexample, not a reproduction of Baird's larger example. It does not say every off-policy approximation diverges.

## DQN: replay and a slowly changing target

A DQN uses a neural network $Q_w(s,a)$ for a discrete action set. A second network $Q_{\bar w}$ supplies targets. Store observed tuples $(s,a,r,s',z)$ in a replay buffer, where $z=1$ means true termination. For a sampled mini-batch,

$$
y_i=r_i+\gamma(1-z_i)\max_{a'}Q_{\bar w}(s_i',a'),\qquad
L_B(w)=\frac1{2B}\sum_i[Q_w(s_i,a_i)-y_i]^2.
$$

Treat $y_i$ as constant during differentiation. The online network changes by gradient descent; after a chosen number of updates, copy $w$ into $\bar w$. A soft target update is another option, but the experiment uses exact periodic copies.

The data flow is:

1. Behavior policy interacts with the environment and records transitions.
2. Replay samples previously recorded transitions to form a batch.
3. The target network computes the bootstrap, with a terminal mask.
4. The online network predicts the selected action values and receives gradients.
5. Periodically synchronize the target network, changing the regression targets.

Replay reduces the immediate sequential correlation and reuses data. It does not make a finite dataset independent of how it was collected, nor guarantee coverage. A target network makes each short optimization phase more stable by slowing target changes; it does not remove approximation bias, maximization bias, or all instability.

Our implementation is a deliberately small DQN teaching experiment: one-hot state input, a 16-unit tanh hidden layer, and two action outputs. It collects 1,000 uniform-policy episodes first, verifies all six nonterminal pairs appear, then performs 3,000 replay updates of batch size 32, learning rate 0.03, and target synchronization every 100 updates. This offline dataset is sufficient for this deterministic tiny grid. Success here is not evidence that arbitrary offline DQN datasets are adequate.

The terminal target is always $r$, even if the network predicts a nonzero terminal output. The script checks every network gradient against central finite differences with frozen targets, including repeated states in a batch.

## Check your understanding

1. Can nonlinear state features define a linear approximator? **Yes.** Linearity refers to the parameters $w$.
2. Does semi-gradient TD minimize true value error? **Not generally.** Its equilibrium solves the projected Bellman equation; the constant-feature grid gives different numerical answers.
3. Why not use the stationary distribution under the grid's uniform policy for every fit? **It concentrates on the terminal state**, discarding nonterminal errors.
4. Does a target network make DQN supervised learning with permanent labels? **No.** The labels change when the target network is synchronized.
5. Can an exactly representable value still be unstable under TD? **Yes.** Representation capacity alone does not ensure stable sampling-weighted drift.
