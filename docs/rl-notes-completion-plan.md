| 位置 | 问题 | 修正方向 |

| 第 1 章，第 35 行 | 奖励的 Markov 性右侧误写成状态转移；动作时间下标也与第 2 章冲突 | 统一为在 `S_t` 采取 `A_t` 后得到 `R_{t+1}, S_{t+1}`；分别写正确的条件概率 |
| 第 1 章，第 31–33 行 | 将目标设为可离开、可重复得奖的普通状态，与零奖励吸收态一起表述为统一转换 | 说明零奖励吸收态可保留原终止任务的回报；允许重复进入领奖通常改变任务目标，不保证等价 |
| 第 2 章，第 22 行 | 循环矩阵右乘已经移位的 `[v_2,v_3,v_4,v_1]^T`，重复移位 | 应右乘 `[v_1,v_2,v_3,v_4]^T`；逐行核验等式 |
| 第 2 章，第 80 行 | 条件期望左侧丢失 `S_t=s` | 保留条件，与右侧按该状态的策略求和一致 |
| 第 2 章，第 119、132 行 | 矩阵元素定义方向写反；展开式左上角也错 | 采用行随机矩阵：`[P_pi]_{ij}=p_pi(s_j|s_i)`；左上角为 `p_pi(s_1|s_1)` |
| 第 2 章，第 156–159 行 | 具体例子中 `P_pi` 右乘奖励向量 | 应右乘价值向量 `v_pi` |
| 第 2 章，第 189 行及文末 | `q_pi(s|a)` 记号错误；通过比较加权和就断定每项相等，推导不充分；v/q 等价说得过强 | 从条件期望直接推导 `q_pi(s,a)`。已知策略时 q 可得到 v；由 v 恢复 q 还需要奖励/转移模型 |
| 第 3 章，第 30 行 | 定义单个转移矩阵元素时额外对下一状态求和 | 应为 `p_pi(s'|s)=sum_a pi(a|s)p(s'|s,a)`；原式会把每个元素算成 1 |
| 第 3 章，第 63、64、72、82 行 | 极限写成 `k→0`；定理缺完备性与自映射条件；BOE 未指定范数 | 改为 `k→∞`；在完备空间上表述定理。BOE 使用无穷范数证明压缩性，不能由“范数可选”推断其对任意范数都压缩 |
| 第 3 章，第 107–109 行 | 声称任意 `a≠0` 的奖励仿射变换保持最优策略 | 保持最大化目标的条件为 `a>0`。还需说明常数平移作用于无限折扣回报的每一步，包括吸收后的步骤；变长且到终点截断的回报不能直接套用 |

奖励变换的最小反例：单状态、两个动作、每步奖励分别为 1 和 2。原任务总是选奖励 2 的动作；若乘以 -1，则应选奖励 -1 的动作，最优策略发生改变。

同时修正常规记号和英语拼写：`discount factor`、`expected value`、`future rewards`、`policies`；第 2 章奖励向量括号；第 3 章最优策略定义缺少 `(s)`、`q*(a,s)` 参数颠倒、分段式多余字符等。这些放在数学核对之后统一处理。
