## 数值验收

命令：

```bash
MPLCONFIGDIR=/tmp/rl-mpl python3 public/rl/ch1-6.py \
  --output public/rl/results.json \
  --plot public/rl/stochastic-approximation.png
```

环境：Python 3.12.3、NumPy 1.26.4、Matplotlib 3.6.3。结果、种子和预算保存在 `public/rl/results.json`。脚本内使用 `np.linalg.solve`，所有解析一致性断言使用 `atol=1e-12, rtol=0`。

- 均匀策略价值：`(9/11, 10/11, 10/11, 0)`，Bellman 残差为 0（浮点计算结果）。
- 最优价值：`(0.9, 1, 1, 0)`；VI、PI、两步截断 PI、枚举策略一致。
- 均匀策略 MC 预测平均状态 RMSE：100/1,000/10,000 回合对应约 0.012451/0.003703/0.001293；正文同时报告跨种子标准差。
- 三类 MC 控制的五个种子都恢复最优贪心策略；epsilon 0.2 的行为策略价值为 81/91，正文明确区分它与贪心策略的 0.9。
- 随机近似的最终 RMSE：1/n 约 0.001472，固定 0.05 约 0.016672，1/(n+1)² 约 0.410582。解析参考解释了采样误差、噪声平台和残余偏差。
- MC 控制中使用 200 步上限；初始回报与复用的后缀回报采用不同截断误差界，正文明确说明，未把截断假装成终止。

这些实验是有限样本的复现，不替代正文的数学证明，也不推断更复杂环境的表现。
