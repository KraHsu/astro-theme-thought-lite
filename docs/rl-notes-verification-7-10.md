## 可复现实验

交付文件：

- `public/rl/ch7-10.py`：独立可运行的后四章实验脚本。
- `public/rl/results-7-10.json`：设置、种子、精确值、采样结果与断言记录。
- `public/rl/learning-7-10.png`：从同一运行生成的预测和策略学习图。
- `public/rl/requirements.txt`：沿用 NumPy 1.26.4、Matplotlib 3.6.3。

实测 Python 3.12.3。运行命令：

```bash
MPLCONFIGDIR=/tmp/rl-mpl python3 public/rl/ch7-10.py \
  --output public/rl/results-7-10.json \
  --plot public/rl/learning-7-10.png
```

主要结果：

| 检查 | 观察与边界 |
| --- | --- |
| TD 控制 | 四种算法各十种子均恢复价值 0.9 的贪心策略；epsilon=0.2 的行为策略价值为 81/91 |
| 配对预测 | 5,000 回合时 MC 平均 RMSE 0.001730，TD 0.005969；正文如实保留这个特定设置下的结果 |
| 线性 TD | 常数特征与两特征模型到各自 TD 固定点的平均 RMSE 为 0.002480、0.001814；不混淆拟合偏差与采样误差 |
| DQN | 五种子最优贪心价值均为 0.9，最大最终 q RMSE 低于 1e-8；是充分覆盖的微型确定性数据集 |
| 策略梯度 | 3 点中心差分的最大坐标差低于 9e-12，断言容差 1e-9 |
| 神经网络梯度 | 全参数中心差分最大差约 9.34e-12，断言容差 1e-9；固定目标且包含重复状态 |
| 基线方差 | 100 回合批次的协方差迹：无基线约 0.003010，精确价值基线约 0.000295 |
| 演员学习 | 3,000 回合、20 种子：REINFORCE/QAC/A2C 平均真实价值约 0.893609/0.893486/0.893874，正文及 JSON 同时报标准差 |
| 离策略梯度 | 完整状态与动作修正相对精确梯度的绝对容差为 1e-12；动作修正单独使用存在可计算偏差 |
| 连续动作 AC | 20 种子最终动作均值 0.699925、样本标准差 0.000929，已知最优点 0.7；另有解析梯度有限差分检查 |
