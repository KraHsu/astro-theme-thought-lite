## 复核结论与修订

逐章复核了英文主稿、中文摘要、实验实现、前后链接及此前的语言导航与 Feed 修复。未发现新的数值计算错误；发现并修正了以下适用条件或说明问题：

1. 第 5 章：首次访问状态在本例中至多发生于第 1 步，但首次访问退出动作可能更晚。补充了状态—动作对的分析：晚到的退出动作立即终止，只有早期起步／边界循环动作的截断后缀需要缺失尾项界。
2. 第 7 章：收敛条件补充步长应由观察本次转移之前的信息确定，避免让步长依赖当前噪声而破坏条件期望分析。
3. 第 8 章：将“平稳分布集中于终点”明确限定为本章评估的均匀策略；补充总在 B 向右会产生其他吸收类的反例。中文摘要同步修订。
4. 第 8 章：明确通常的半梯度 TD 不一定是某个固定标量损失的梯度，避免把不同更新方向直接称为不同优化目标。
5. 第 10 章：连续动作例子的奖励噪声改为明确的条件零均值 `E[xi | a] = 0`；实际实验使用独立高斯噪声，原数值结果不变。
6. MC Basic 原先没有填入结果 JSON 的截断次数与起始对采样量；补上统计。五个种子均为零截断，每个起始对有 1,800 个初始回报样本。
7. 第 1 章统一算例介绍更新为十章范围，单独标明反例与连续动作任务。

两份实验脚本重新完整运行。后四章结果与已记录 JSON 完全一致；前六章除新增 MC Basic 统计字段内容外，其余结果完全一致。核验范围包括解析价值、规划算法、MC、TD、投影近似、梯度有限差分、离策略权重和连续动作实验。有限样本结果的适用范围及外部收敛定理依赖仍在正文明确说明。
